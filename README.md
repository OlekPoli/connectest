# Connect’Est

Prototype du site Connect’Est : conseils, rencontres et ressources pour l’insertion professionnelle des jeunes du Grand Est et des zones frontalières.

Site : https://olekpoli.github.io/connectest/

## Fichiers
- `index.html` : le site complet (FR / EN, carte interactive, calculateur de trajets, enquête, mentions légales). Photo et logos intégrés.
- `connectest-guide-frontalier.pdf` / `connectest-guide-cross-border.pdf` : guides à télécharger (FR / EN)
- `LICENSE` : tous droits réservés

## Technique
HTML, CSS et JavaScript sans dépendance. Carte en SVG générée à partir de Natural Earth et france-geojson. Routage par ancres, données de trajets et textes dans le script.

## Sources
Enquête Connect’Est (été 2026, n = 207), Insee Analyses Grand Est n° 188, Frontaliers Grand Est 2025, L’Étudiant. Temps de trajet en train : SNCF Connect, TER Grand Est, CFL et comparateurs.
